# BrightPath Academy

BrightPath Academy is a responsive landing page for a coaching institute. It presents course information, faculty details, student testimonials, and an admission enquiry section in a simple and organized layout.

I built this project to practice my HTML, CSS, and JavaScript skills and to learn how to turn a website idea into a working webpage. I also used AI tools to assist with parts of the development process.

## Features

- Course information for different classes and competitive exams
- Faculty profiles and student testimonials
- Admission enquiry section
- Responsive layout for different screen sizes
- Clean and easy-to-navigate design

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Run Locally

1. Clone this repository:

   ```bash
   git clone https://github.com/rajputriya708-jpg/brightpath-academy.git
   ```

2. Open the project folder.
3. Open `index.html` in your browser.
